## 0.1.0

Initial Python and JavaScript/TypeScript SDK release:
- Incremental TTS streaming and file downloads, with audio controls preserved.
- Voice catalogue, consent-required cloning, deletion, controls, dialects and balance.
- File transcription (JSON/SSE), live WebSocket transcription and translation.
- Python sync/async clients; Node ESM/CommonJS and TypeScript declarations.
- Typed API errors, timeouts, cancellation, safe retries and explicit idempotency.
